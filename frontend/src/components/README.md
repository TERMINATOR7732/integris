# Frontend Components Directory

Modular UI components for INTEGRIS will be placed here in Phase 3:
- `common/`: Badges, buttons, modals, layout shells
- `upload/`: Ingestion zone, target column selector
- `overview/`: Trust score gauge, executive verdict card
- `findings/`: Forensic findings feed, evidence drilldown drawers
- `columns/`: Column-level distribution charts & profiles
- `inspection/`: Anomaly-highlighted sample record inspector
